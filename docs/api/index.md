# API 参考

## 函数

| 函数 | 说明 |
|------|------|
| `convert()` | 将 Processing 代码转换为 Vue 组件 |
| `parse()` | 解析 Processing 代码 |
| `generate()` | 从 AST 生成 Vue 组件 |

## 类型

| 类型 | 说明 |
|------|------|
| `ConversionOptions` | 转换配置选项 |
| `ParsedCode` | 解析后的代码结构 |
